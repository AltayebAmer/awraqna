## البنية

```

assets/gen/<domain>.js  منطق كل مجال — نصوص فقط، ممنوع لمس DOM
assets/page-<domain>.js ربط المجال بالنواة
assets/sheet.css        ★ الطبقة الوحيدة التي تُطبع
assets/fonts/           ٥ خطوط SIL OFL مجزّأة (237KB)
```

## قواعد لا تُخالَف

- **اقرأ `PROJECT_MAP.md` قبل أي تعديل** — فيه كل قرار محسوم وسببه.
- `assets/gen/*.js` منطق نقي: يعيد نصوصاً ولا يلمس DOM (ولذلك يُختبر في node).
- إخفاء الطباعة **بالإقصاء** `body > *:not(#print-root)` لا بقائمة يدوية.
- **صفر تبعيات · صفر CDN.** الخطوط محلية.
- لا فيضان أفقي حتى عرض 320px — يُقاس، لا يُفترض.

## التحقق

المخرَج ورق، فالمعيار عدد الصفحات لا الشكل على الشاشة:

```bash
python3 -m http.server 8080
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --no-pdf-header-footer --print-to-pdf=out.pdf \
  http://localhost:8080/math/
```

كل المخرجات **A4 بالضبط** (210×297 مم، مقيسة من `MediaBox`).
